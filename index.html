この本の核心（45枚より）

  • 進捗管理は「報告」ではなく「改善」のためにある
  • まず現状（事実）を直視し、その後に進捗（見通し）を判断する
  • ギャップが一目でわかる積み上げ棒グラフが最強
  • 改善策は「量 → やり方 → 質」の順で、一度に一つ
  • シンプルで毎日続けられる仕組みこそ成果につながる

使い方ガイド ／ このアプリの操作まとめ

📅 月の切り替え

画面右上の ‹ › で月を移動します。すべての画面はその月の数字を表示します。年度（4月〜翌3月）で管理しています。

🚗 損保成績（毎日の入力）

  1. その日に上げた契約の保険料を、緑の 「＋今日上げた分」 欄に入力して 加算（Enterでも可）。
  2. 累計が自動で増え、グラフ・ギャップに即反映されます。
    例：初日500を加算 → 翌日300を加算 → 現状累計は自動で800
  3. 入力ミスは「現状累計」欄を直接書き換えて修正できます。
  4. 新規の目標は「合計目標 − 更新目標」で自動計算されます。毎月、合計カードの更新目標だけ入れ替えてください。

📆 将来の契約予定（前倒し契約）

  1. 損保ページ下部の 「契約を追加」 で、種別・計上月・保険料・獲得日を入力して追加。
  2. 例：6月に獲得した8月計上の更新契約 → 計上月を「8月」にすれば8月の成績に自動計上。
  3. 登録した契約は「先行獲得（翌月以降に計上予定）」に月別の見込みとしてまとまります。
  4. 計上月へ月ナビで移動すると、その月の現状に自動で乗ります。

💜 生命保険

損保と同じく、緑の「＋今日上げた分」で手数料（千円）を加算していきます。

🎯 行動KPI ＆ 日次記録

  1. 日次記録タブで「＋今日を追加」→ 経営者接触・建築業価値提供・未来資産構築の件数を入力。
  2. 入力した数字は週ごとに自動集計され、行動KPIタブの週バー・月間達成率に反映されます。
  3. 各KPIの週目標はKPIタブで設定します。

📊 推移グラフ

年度（4月〜翌3月）のギャップ推移を積み上げ棒で表示。棒の上＝現状、棒の中＝ギャップ（不足分）。上のメニューで指標を切り替えられます。ギャップが減れば改善効果あり・増えれば逆効果と自動診断します。

📈 年間サマリー

年度の4月から当月までの累計を、年間目標と比べて表示。各項目の年間目標はその場で編集できます。

💾 バックアップ・復元・元に戻す

  1. バックアップ保存：全データをファイルに保存。月初など定期的に保存しておくと安心です。
  2. 復元：保存したファイルを選んでデータを戻します。
  3. ↶ 元に戻す：直前の操作（加算・保存・契約の追加削除など）を取り消します。

※ データはこのブラウザ内に保存されます。ブラウザのデータを消すと失われるので、バックアップ保存を習慣にしてください。
